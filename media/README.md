# Short patient guides

Illustrated demo drafts: journey, privacy, preparation and results, with separate English and Arabic MP4s, matching WebVTT captions and posters. English: approximately 30–32s, voiced by Karen with conversational phrasing and varied pauses. Arabic: approximately 39–41s. Synthetic narration; not clinician-approved collection instructions.

`js/videos.js` configures language-specific media and measured durations. Written transcripts remain available, including when a source is empty. Scene artwork (`media/artwork/sirr-scenes.png`) was AI-generated for the hackathon; narration uses synthetic macOS text-to-speech voices.
